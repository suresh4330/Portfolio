## Overview

The **Movie Booking System** is an interactive web application that bridges external media catalog APIs with geospatial cinema discovery and booking simulations.

## Architecture & API Integrations

- **TMDB API Integration**: Dynamically queries now-playing films, genre classifications, cast details, and high-resolution posters.
- **Geospatial Mapping**: Integrates OpenStreetMap to locate cinemas and calculate theater proximity for users.
- **Booking State Machine**: Manages seat reservation states, showtime selection, and simulated payments with local persistence.
